# n8n Workflow Debugging Skill

Expert guidance for debugging and diagnosing n8n workflow failures.

- 🔍 Execution analysis and tracing
- 📊 Error pattern recognition
- 🎯 Root cause identification
- 🛠️ Evidence-based troubleshooting
- ⚡ Performance bottleneck detection

Automatically when you ask about:
- "Why is my workflow failing?"

## Quick Start

1. **Get execution data** with `n8n_get_execution()`
2. **Identify failing node** from execution tree
3. **Check error message** against ERROR_CATALOG.md
4. **Apply appropriate fix** from catalog
5. **Validate and test**
