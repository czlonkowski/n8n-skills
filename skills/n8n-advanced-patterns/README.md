- **Error Handling** - Try-catch, retry logic, circuit breaker, DLQ
- **Branching** - Conditional logic, switch patterns, multiple branches

- **Orchestration** - Multi-stage pipelines, fan-out/fan-in, state machines
- **Data Transformation** - Normalization, aggregation, deduplication

✅ Idempotent operations - Safe to run multiple times
✅ Graceful degradation - Reduce features instead of failing completely
✅ Bulkhead pattern - Isolate failures
✅ State machines - Track explicit workflow states
✅ Async processing - Long tasks don't block workflow
